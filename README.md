# SEVILLE INFO

Сайт sevilleinfo.ru. Хостинг: GitHub Pages (с 20.10.2026), домен через DNS в Cloudflare (записи A на 185.199.108–111.153 и CNAME www → jarflow1.github.io, все DNS only). Пуш в main → сайт обновляется за 1–2 минуты.

## Правила для новостей
- На главной и на сайте держим только 3 самых свежих новости. Добавляя новую, удаляем самую старую (и её страницу, и строку в sitemap.xml).
- Каждая новость: короткая карточка на главной + отдельная страница news-*.html с подробным текстом и ссылкой на источник.
- Фото из СМИ не используем — только присланные владельцем сайта.
- Новая страница новости копирует <head> существующей (иконки, og:-теги с картинкой og-image.png); og:title/og:description/og:url/canonical — свои.
- Концерты: у каждого <article class="event"> есть data-date="ГГГГ-ММ-ДД"; прошедшие скрываются скриптом сами.
- На всех страницах стоит Яндекс Метрика (счётчик 113666219): скрипт в <head>, noscript сразу после <body>. Новые страницы — тоже.
- Лимит 16 КБ больше не действует (сайт ушёл с Cloudflare-хостинга на GitHub Pages). Картинки можно, но сжимать в WebP. Прокси Cloudflare (оранжевое облако) для записей домена НЕ включать.
- Тест quiz.html: вопросы только по проверенным фактам (источники: 24СМИ, StarHit, 360.ru, Новое радио, Рамблер, МУЗ-ТВ). Новые вопросы — тоже только с проверкой.
- Сезонные темы: класс .hw на <html> включается скриптом по дате (Хеллоуин 18.10–01.11). Без картинок — только CSS/SVG.
- НЕ УДАЛЯТЬ: googleea2108c41e6d0b2a.html (Google Search Console) и yandex_bc4107c96551f332.html (Яндекс Вебмастер) — файлы подтверждения прав.
- Схема контента (решение владельца): Telegram — оперативно и коротко; сайт — подробные материалы. Автопостинга с сайта в канал НЕТ.
- Блок «Последний релиз» (#release) + окно <dialog id=rel-dlg> со ссылками на площадки. При новом релизе — заменить название, дату и ссылки.
- fan.html — генератор именной фан-карты (canvas 1080×1920, рисуется на устройстве, без картинок). Цель Метрики fan_card_save при сохранении. Цвет берётся из --accent (сезонные темы применяются сами).

- concerts.html — страница «Концерты Artik & Asti» (афиша + JSON-LD MusicEvent для поиска). Концерты дублируются с главной: меняя афишу на index.html, обновить и concerts.html (список и JSON-LD). Блок «Звёзды Востока» скрывается сам после 13.11.2026, потом его можно удалить.
- quiz.html — кнопка «Сохранить для сторис» рисует картинку результата 1080×1920 (canvas), цель Метрики quiz_story_save.
- Главная: показывает только 3 ближайших концерта (лишние убирает скрипт), остальные — на concerts.html по ссылке «Вся афиша». Фан-карта и тест — один блок «Для фанатов» (#fans).
- Цвета: основной постоянный стиль — салатовый #b7ff35 на чёрном (логотип INFO, кнопки, даты, отсчёт). Оранжевый, летучие мыши и паутина — только Хеллоуин (18.10–01.11), со 2 ноября сайт сам возвращается в зелёный. В новых страницах и элементах акцент только через var(--accent), цвет руками не вписывать (кроме определения --accent в :root и .hw).
- Персональные данные: privacy.html — политика конфиденциальности (ссылка в подвале каждой страницы). На всех страницах плашка про cookies (#ck, запоминается в localStorage ck_ok). Вебвизор в Метрике выключен (webvisor:false) — не включать. Новые страницы: копировать плашку и ссылку на политику. Владелец подаёт/подал уведомление в РКН (pd.rkn.gov.ru).

- Временные новости: у карточки на главной атрибут data-until="ГГГГ-ММ-ДД" — после этой даты скрипт её прячет (в счёт «3 свежих» не входит). После срока удалить страницу, картинку и строку в sitemap.xml.
- Названия в афише — названия мероприятий, без добавления имени Севиль. В #events и concerts.html — только события с посещением.
- Шоу и эфиры: отдельный блок #shows на главной, между выступлениями и новостями; карточки .broadcast, дата показа, канал/площадка, часовой пояс и ссылка на подробности. До 3 ближайших карточек, прошедшие скрываются; пустой блок и ссылка в меню скрываются автоматически. JSON-LD BroadcastEvent находится на главной. Новости о шоу остаются в #news.

- Первый экран: компактное текстовое вступление без фонового фото. Справа (на телефоне ниже) — ближайшее выступление с датой и отсчётом. Исходные фотографии сохранены в img/, на главной не загружаются.

- Навигация и подвал едины на всех страницах: Афиша, Шоу и эфиры, Новости, Для фанатов, Telegram. Общие стили — site.css, мобильное меню — site.js. При изменении этих файлов обновлять параметр версии в ссылках на всех страницах.
- Дата «Афиша обновлена» в concerts.html — дата реального редактирования, не текущая дата посетителя. Время концертов местное; у телепоказов указывать часовой пояс или явно писать, что он уточняется.
- Ссылка «Шоу и эфиры» в общем меню имеет data-shows-until с датой самого позднего анонса. При добавлении нового показа обновлять этот атрибут на всех страницах. Просроченная ссылка скрывается общим скриптом.
- Новости: внизу каждой статьи есть переходы к разделам и двум другим текущим новостям. При замене одной из трёх новостей обновлять эти ссылки. Архив новостей пока не добавлен.
- Мобильная афиша: дата, название с описанием и кнопка расположены друг под другом; текст занимает всю ширину. На fan.html поля находятся перед предпросмотром.
