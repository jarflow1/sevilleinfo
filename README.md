# SEVILLE INFO

Сайт sevilleinfo.ru. Публикуется автоматически через Cloudflare Workers при пуше в main.

## Правила для новостей
- На главной и на сайте держим только 5 самых свежих новостей. Добавляя новую, удаляем самую старую (и её страницу, и строку в sitemap.xml).
- Каждая новость: короткая карточка на главной + отдельная страница news-*.html с подробным текстом и ссылкой на источник.
- Фото из СМИ не используем — только присланные владельцем сайта.
