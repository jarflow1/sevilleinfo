# SEVILLE INFO

Сайт sevilleinfo.ru. Хостинг: GitHub Pages (с 20.10.2026), домен через DNS в Cloudflare (записи A на 185.199.108–111.153 и CNAME www → jarflow1.github.io, все DNS only). Пуш в main → сайт обновляется за 1–2 минуты.

## Правила для новостей
- На главной и на сайте держим только 3 самых свежих новости. Добавляя новую, удаляем самую старую (и её страницу, и строку в sitemap.xml).
- Каждая новость: короткая карточка на главной + отдельная страница news-*.html с подробным текстом и ссылкой на источник.
- Фото из СМИ не используем — только присланные владельцем сайта.
- Новая страница новости копирует <head> существующей (иконки, og:-теги с картинкой og-image.png); og:title/og:description/og:url/canonical — свои.
- Концерты: у каждого <article class="event"> есть data-date="ГГГГ-ММ-ДД"; прошедшие скрываются скриптом сами.
- На всех страницах стоит Яндекс Метрика (счётчик 113666219): скрипт в <head>, noscript сразу после <body>. Новые страницы — тоже.
- Лимит 16 КБ больше не действует (сайт ушёл с Cloudflare-хостинга на GitHub Pages). Картинки можно, но сжимать в WebP. Прокси Cloudflare (оранжевое облако) для записей домена НЕ включать.
- Тест quiz.html: вопросы только по проверенным фактам (источники: 24СМИ, StarHit, 360.ru, Новое радио, Рамблер, МУЗ-ТВ). Новые вопросы — тоже только с проверкой.
- Сезонные темы: класс .hw на <html> включается скриптом по дате (Хеллоуин 18.10–01.11). Без картинок — только CSS/SVG.
- НЕ УДАЛЯТЬ: googleea2108c41e6d0b2a.html (Google Search Console) и yandex_bc4107c96551f332.html (Яндекс Вебмастер) — файлы подтверждения прав.
- Схема контента (решение владельца): Telegram — оперативно и коротко; сайт — подробные материалы. Автопостинга с сайта в канал НЕТ.
- Блок «Последний релиз» (#release) + окно <dialog id=rel-dlg> со ссылками на площадки. При новом релизе — заменить название, дату и ссылки.
- fan.html — генератор именной фан-карты (canvas 1080×1920, рисуется на устройстве, без картинок). Цель Метрики fan_card_save при сохранении. Цвет берётся из --accent (сезонные темы применяются сами).

- concerts.html — страница «Концерты Artik & Asti» (афиша + JSON-LD MusicEvent для поиска). Концерты дублируются с главной: меняя афишу на index.html, обновить и concerts.html (список и JSON-LD). Блок «Звёзды Востока» скрывается сам после 13.11.2026, потом его можно удалить.
- quiz.html — кнопка «Сохранить для сторис» рисует картинку результата 1080×1920 (canvas), цель Метрики quiz_story_save.
- Главная: показывает только 3 ближайших концерта (лишние убирает скрипт), остальные — на concerts.html по ссылке «Вся афиша». Фан-карта и тест — один блок «Для фанатов» (#fans).
